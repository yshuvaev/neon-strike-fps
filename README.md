# NEON STRIKE

Браузерный шутер от первого лица в процедурно сгенерированной 3D-арене.
Чистый JavaScript: Three.js (WebGL) + cannon-es (физика). Никаких ассетов —
все текстуры рисуются на canvas в рантайме (включая normal-мапы, карты эмиссии
и небо), весь звук синтезируется через WebAudio.

## Запуск

Это статический сайт — достаточно открыть `index.html` через любой веб-сервер
(модули ES требуют http, не file://):

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

Зависимости (three, cannon-es) подтягиваются с CDN через import map.

## Игровой процесс

- Волны врагов-трое типов: **runner** (быстрый, ближний бой), **brute**
  (медленный танк), **spitter** (держит дистанцию, стреляет плазмой)
- Хитскан-винтовка: хедшоты ×2.2, комбо-множитель за серии убийств
- Красные бочки взрываются с цепной реакцией и уроном по области
- Очки, волны, личный рекорд в localStorage

## Технологии

- **Three.js r160** — рендер, PCFSoft-тени, ACES tone mapping, UnrealBloom
- **cannon-es** — динамические ящики/бочки, импульсы взрывов, физические трупы
- Кинематический контроллер игрока (капсула vs AABB) с раздельным
  разрешением столкновений по осям — можно запрыгивать на ящики и платформы
- Процедурные текстуры 1024px с normal-мапами (Sobel по карте высот),
  процедурное небо со звёздами и туманностями
- Пулы частиц (искры/дым), трассеры, вспышки света — без аллокаций в кадре
- Синтезированный звук: выстрелы, взрывы, рикошеты, эмбиент
